# Inventory & Stock Management System (Google Sheets)

## 📋 Project Overview
This is a dynamic Inventory Management System developed in Google Sheets. It is designed to track stock movements (Inwards/Outwards) automatically and provide real-time updates on stock availability, helping businesses avoid stockouts or overstocking.

## 🛠 Key Features
- **Real-Time Stock Tracking:** Automatically calculates current inventory levels based on transaction logs.
- **Automated Low-Stock Alerts:** Uses Conditional Formatting to highlight items that fall below the safety stock level.
- **Categorized Database:** Organized product lists with dropdown menus for error-free data entry.
- **Dynamic Summary:** Instant view of total stock-in, stock-out, and remaining balance.

## 🧰 Functions & Formulas Used
- **SUMIF/SUMIFS:** For calculating total ins and outs per product.
- **IF Logic:** To generate custom alerts (e.g., "Restock Now").
- **Data Validation:** For creating searchable dropdown lists.
- **Conditional Formatting:** For visual status indicators.
